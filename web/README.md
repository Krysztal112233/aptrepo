# Web UI — pixel repository index

Pixel-art / DaisyUI frontend that renders what this APT repository ships and which
Debian suites each package supports. Data is fetched at runtime from
`{baseurl}/index.json` (generated by `scripts/repo-index.ts`), so the page is always
in sync with the published repository.

## Stack

Vue 3 + TypeScript + Vite 8 (Rolldown — no esbuild anywhere in the dependency tree)
+ Tailwind CSS 4 + DaisyUI 5 (two custom themes: `departure` faded-industrial
paper, `departure-dark` night terminal).

## Font

All type is [Departure Mono](https://departuremono.com) v1.500 by Helena Zhang
(SIL OFL 1.1), self-hosted: `src/assets/DepartureMono-Regular.woff2` is bundled
by Vite (hashed, relative URL — works under any baseurl sub-path), and the OFL
license ships via `public/fonts/OFL.txt`. For pixel-perfect rendering, keep all
font sizes at multiples of 11px (11 / 16.5 / 22 / 33 / 44 / 55). Decorative
glyphs (░ ▒ ▓ █ ★ ▚ ❯ → box-drawing) are provided by the font itself — no emoji.

## Commands

```sh
pnpm install     # install dependencies
pnpm dev         # dev server — proxies /index.json, /dists, /pool …
                 # to VITE_REPO_ORIGIN (default http://127.0.0.1:8137);
                 # serve the repo locally with:
                 #   python3 -m http.server 8137 --directory repo
pnpm build       # production build — output goes DIRECTLY into ../repo/
                 # (index.html + assets/), ready to be published at the baseurl
pnpm typecheck   # vue-tsc --noEmit
```

or via the repo-wide just recipes: `just web-install`, `just web-dev`, `just web`.

pnpm note: `pnpm-workspace.yaml` sets `allowBuilds: { esbuild: false }`.
Vite 8 never invokes esbuild (it is only an auto-installed optional peer),
so its postinstall is explicitly skipped — without this entry pnpm 11 aborts
installs/runs with `ERR_PNPM_IGNORED_BUILDS`.

## Notes

- `vite build` uses `emptyOutDir: false` so the real repository content in
  `../repo/` is never wiped; the `prebuild` script only removes stale hashed
  assets (`../repo/assets/`).
- `base: "./"` keeps asset URLs relative, so the page works whether the
  repository is hosted at a domain root or under a sub-path.
- Tailwind class names for suite colors are listed as full literals in
  `src/repo.ts` (`SUITE_STYLES`) — do not replace them with string
  interpolation, or the build-time scanner will drop them.
